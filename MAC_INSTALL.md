# StudyPilot on macOS

StudyPilot works on macOS in Google Chrome and Microsoft Edge. This package is still a normal Manifest V3 browser extension, so macOS users install it with **Load unpacked** after extracting the ZIP file.

## Files for Mac users

- `dist/StudyPilot-mac-1.0.0.zip`: Mac-friendly distribution ZIP
- `dist/StudyPilot-mac-1.0.0/`: Extracted folder with the extension files

## Install on Chrome for macOS

1. Download or copy `StudyPilot-mac-1.0.0.zip`.
2. Double-click the ZIP in Finder to extract it.
3. Open Chrome.
4. Go to `chrome://extensions`.
5. Enable **Developer Mode**.
6. Click **Load unpacked**.
7. Select the extracted `StudyPilot-mac-1.0.0` folder.

## Install on Edge for macOS

1. Download or copy `StudyPilot-mac-1.0.0.zip`.
2. Double-click the ZIP in Finder to extract it.
3. Open Edge.
4. Go to `edge://extensions`.
5. Enable **Developer Mode**.
6. Click **Load unpacked**.
7. Select the extracted `StudyPilot-mac-1.0.0` folder.

## Notes

- StudyPilot supports Chrome and Edge on macOS without code changes.
- Safari cannot use this package directly.
- The extension does not run on restricted browser pages such as `chrome://` pages, `edge://` pages, or the Chrome Web Store.
